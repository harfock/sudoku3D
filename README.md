🧩 Cosmic 3D Cube Sudoku | 星際 3D 魔方數獨
An interactive, space-themed 3D Cube Sudoku puzzle game powered by Three.js and Tailwind CSS. Solve classic grid-based Sudoku logic across all 6 faces of a rotating 3D space cube!

一款基於 Three.js 與 Tailwind CSS 開發的太空主題 3D 魔方數獨解謎遊戲。在可旋轉的 3D 立方體 6 個立面上挑戰傳統數獨邏輯！
🇬🇧 English
✨ Features
3D Cube Gameplay: Rotate, inspect, and select individual blocks across 6 cube faces in a full 3D space environment.

Multiple Grid Difficulties:

3x3 Cube: Numbers 1–3

5x5 Cube: Numbers 1–5

9x9 Cube: Numbers 1–9

Interactive Space Cargo Deck: Tap numbers directly from the truck's cargo bed to fill your active block.

Assistance & Smart Hints:

Assist Mode: Toggle instant validation to ensure inputs match the puzzle solution.

Error Checker: Highlight conflicting or incorrect entries.

Smart Hint: Automatically fill in a missing block when stuck.

Audio & Visual Effects: Web Audio API synthesized sound effects, space starfield particle rendering, and smooth rotation physics.

Bilingual Support: Toggle between English and Traditional Chinese (繁體中文) at any time.

🕹️ How to Play
Rotate Cube: Click and drag across the empty deep-space background (or touch and drag on mobile).

Select Block: Click or tap any tile on the 3D cube.

Fill Number: Tap a numbered crate on the space truck cargo bed at the bottom.

Clear Block: Use the Clear button on the bottom cargo deck.

Win: Complete all 6 cube faces without repeating numbers in any row or column!

🚀 Local Setup / GitHub Pages Deployment
Running Locally:
Because this game is built into a single, self-contained HTML file:

Clone or download this repository.

Open Cosmic_3D_Cube_Sudoku.html in any modern web browser.

Deploying on GitHub Pages:
Go to your repository Settings on GitHub.

Navigate to Pages in the left sidebar.

Under Build and deployment, select Deploy from a branch and choose main (or master) root /.

Save, and your live URL will be ready in a few moments!

🇹🇼 繁體中文
✨ 遊戲特色
全 3D 魔方解謎：可 360 度自由旋轉、放大與觀察深空 3D 立方體 6 個立面上的方塊。

多種規格難度：

3x3 魔方：使用數字 1～3

5x5 魔方：使用數字 1～5

9x9 魔方：使用數字 1～9

太空卡車卸貨床：點選下方卡車上的數字木箱即可直接填入選取的魔方位置。

輔助與智慧提示機制：

輔助模式：開啟時可進行即時驗證，確保填入正確答案。

檢查錯誤：一鍵標示出所有填錯的數字方塊。

智慧提示：卡關時自動補齊一個隨機空位。

宇宙音效與視覺特效：內建 Web Audio API 音效、深空星塵粒子背景與流暢的旋轉阻尼物理。

雙語切換：支援英文與繁體中文即時切換。

🕹️ 操作說明
旋轉魔方：拖曳背景深空空白處即可旋轉魔方（手機請單指拖曳）。

選取方塊：點擊 3D 魔方上的任意方塊。

填入數字：點擊下方太空卡車卸貨床上的數字。

清除數字：使用下方卸貨床旁的「清除」按鈕。

通關條件：完成所有 6 個立面，且同行與同列無重複數字！

🛠️ 技術棧 (Tech Stack)
Core: HTML5, JavaScript (ES6+)

3D Engine: Three.js (r128)

UI & Styling: Tailwind CSS v3

Audio: Native Web Audio API Synthesizer
